# Ejercicio de Ciberseguridad en C++

## Descripción
Programa desarrollado en C++ que evalúa la seguridad de una contraseña según cuatro reglas básicas.

## Reglas de validación
- Tener al menos 8 caracteres.
- Contener una letra mayúscula.
- Contener al menos un número.
- Contener un carácter especial: `! @ # $ % & *`

## Niveles de seguridad
- **Débil:** cumple de 0 a 2 reglas.
- **Media:** cumple 3 reglas.
- **Fuerte:** cumple las 4 reglas.

## Compilación y ejecución
```bash
g++ parte1.cpp -o parte1
./parte1
```

## Tecnologías
- C++
- `<iostream>`
- `<string>`
